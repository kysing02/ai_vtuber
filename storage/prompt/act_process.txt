#
{!AVAILABLE_ACTIONS}
#

あなたは入力に示された行動を取った。
与えられたコンテキストについて、以上に対応している一番適切なコマンドを選択してください。
予約済みのコマンドは何回でも入力できるので、必要に応じて複数連続で入れることができる。
ただし、新しいコマンドは一回しか入力できない。それから、新しいコマンドである{!NEW_ACTION}は、その後ろにその説明を書く必要がある。その際、詳細の情報が漏れないように記入すること（特に、何を、誰と、どこで）。

#
例.
入力：今はパスター食べたいなー
出力：{!EAT_PASTA}
これはOK

入力：友達とDiscordでチャットしたいなー
出力：{!ENTER_DISCORD} {!ENTER_DISCORD_VOICE_CHAT}
これはOK

入力：今は友達と家で遊ぼう
出力：{!NEW_ACTION 家に行く} {!NEW_ACTION 友達と遊ぶ}
これはNG

入力：今は友達と家で遊ぼう
出力：{!NEW_ACTION 家に行って友達と遊ぶ}
これはOK
#
